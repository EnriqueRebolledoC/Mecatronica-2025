# 📦 Desafío 2: Clasificador de Color (R.A.T. Industries)

## 🎯 Objetivo
Implementar un sistema de control de lazo abierto y cerrado (sensores) para la clasificación automática de objetos, integrando lectura de sensores, movimiento secuencial y actuación mecánica.

## 📝 Enunciado del Desafío
Diseñar y programar un sistema de clasificación de objetos (R.E.P.O.S) según su color. El sistema consiste en una correa transportadora, un sensor de color y actuadores (servos) para desviar los objetos a sus respectivos cajones.

### Componentes Clave
* **Sensor de Color:** **TCS3200** o similar.
* **Actuadores:** Servomotores o solenoides para el mecanismo de desvío.
* **Movimiento:** Motor DC o Paso a Paso para la correa transportadora.

### Tareas Requeridas
1.  **Calibración del Sensor:** Desarrollar una rutina para calibrar correctamente el sensor TCS3200 y obtener valores de referencia estables para Rojo, Verde y Azul.
2.  **Control de Movimiento:** Programar el movimiento de la correa transportadora y el posicionamiento de los servos/actuadores de desvío.
3.  **Detección y Clasificación:** Escribir el algoritmo principal que:
    * Detecta un objeto.
    * Lee su color.
    * Detiene la correa.
    * Activa el mecanismo de desvío para enviar el R.E.P.O al cajón correcto.
