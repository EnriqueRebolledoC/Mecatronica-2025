# ⚙️ Desafío 3: Sintonización y Estabilización (Control PID)

## 🎯 Objetivo
Comprender la importancia de los parámetros $K_p$, $K_i$ y $K_d$, y aplicar metodologías de sintonización para lograr un control estable en un sistema dinámico (simulado o físico, similar al robot auto-balancín).

## 📝 Enunciado del Desafío
Dado un sistema mecatrónico que requiere estabilización (por ejemplo, mantener un ángulo o posición de referencia), se debe encontrar la combinación óptima de las constantes PID para minimizar el error de estado estacionario y el tiempo de respuesta, evitando la oscilación excesiva.

### Tareas Requeridas
1.  **Diagrama de Conexiones:** Presentar el esquema del sistema bajo control (incluyendo lazo de control, sensor, microcontrolador y actuador).
2.  **Sintonización de $K_p$:** Encontrar una ganancia proporcional inicial usando el método de **Ziegler-Nichols** (basado en la oscilación sostenida) o un método de prueba y error.
3.  **Sintonización de $K_i$ y $K_d$:** Determinar las ganancias integral y derivativa que eliminan el error de estado estacionario y amortiguan las oscilaciones.
4.  **Control Estable:** Demostrar que el sistema logra estabilizarse alrededor del punto de consigna (setpoint) sin sobreimpulsos excesivos y en un tiempo aceptable.

### Pistas (Hint)
* **Efectos:** Prueba los valores extremos de cada constante para observar su efecto individual en el sistema (respuesta rápida vs. oscilación, estado estacionario, etc.).
* **Inicio:** Comienca solo con $K_p$, luego añade $K_d$ para reducir el sobreimpulso, y finalmente $K_i$ para eliminar el error de *steady-state*.

Subir el `codigo/` con el algoritmo PID implementado y un breve informe (o comentarios en el código) explicando la metodología de sintonización utilizada y los valores finales de $K_p$, $K_i$ y $K_d$.
