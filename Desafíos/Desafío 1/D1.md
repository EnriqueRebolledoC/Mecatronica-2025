# 🚗 Desafío 1: Ratmóvil (Control Básico y Funciones Esenciales)

## 🎯 Objetivo
Familiarizarse con el control de motores DC y la señalización visual, creando una base sólida de funciones que se utilizarán en sistemas robóticos más complejos.

## 📝 Enunciado del Desafío
A partir de un Ratmóvil provisto con un puente H (o driver de motor), se debe escribir el código que permita el movimiento básico y la señalización mediante LEDs.

### Tareas Requeridas
1.  **Funciones de Movimiento:** Implementar las funciones esenciales para accionar los motores: `moverAdelante()`, `moverAtras()`, `girarIzquierda()`, `girarDerecha()`, y `detener()`.
2.  **Señalización LED:** Utilizar LEDs (o luces integradas) para señalizar visualmente el movimiento activo. Por ejemplo:
    * **Adelante:** LED Verde.
    * **Atrás:** LED Rojo.
    * **Giro (Izquierda/Derecha):** LED Amarillo parpadeante.
3.  **Documentación:** Adjuntar al reporte:
    * **Diagrama Esquemático:** Un diagrama claro de la arquitectura de las conexiones (microcontrolador, driver, motores, LEDs).
    * **Código Comentado:** El código debe estar limpio y bien comentado, explicando la lógica de cada función.

## 🛠️ Entregables
Entregar el  `codigo/` con el sketch de Arduino (o similar) y el diagrama.
