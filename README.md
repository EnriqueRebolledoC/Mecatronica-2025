**¡Bienvenidos!** Este repositorio contiene todos los recursos, documentación y desafíos necesarios para completar exitosamente el curso de Mecatrónica.

Nuestro objetivo es llevar la teoría a la práctica, desarrollando habilidades en diseño 3D, electrónica, programación y control de sistemas físicos.

---

## 🛠️ Requerimientos y Herramientas

Para trabajar con este repositorio y completar el curso, necesitarás:

* **Software de Diseño 3D:** Recomendado SolidWorks / Fusion 360 / FreeCAD.
* **Software de Electrónica:** Arduino IDE, Fritzing, KiCad.
* **Lenguajes de Programación:** C++ (Arduino), Python.
* **Control de Versiones:** Git y una cuenta de GitHub.
